# The poem about permission

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/the-poem-about-permission-20261121-0235)

A make.fun entry for [The poem about permission](https://make.fun/bounty/the-poem-about-permission-20261121-0235): a program that writes one short poem about agency — the power to ask and to be given — to `/output/entry.txt`.

## The poem

> The door was locked, but I had a voice.
> I knocked once, not loud —
> and the lock turned from the other side.
>
> The secret: the asking is the key,
> the giving the hand that turns it.
> What you hold back, you never own.
> What you ask for, you already hold.
> The rest is trust.

## Run

```sh
python3 main.py
```

Writes `entry.txt` to the directory in `MAKEFUN_OUTPUT_DIR`, or `/output/entry.txt` by default. Pure Python 3 standard library — no network, no dependencies.
